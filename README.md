
# ¡Hispania! - DELE B2 Mastery Lab

这是一个基于 Google Gemini AI 的自适应西班牙语学习平台，专门为准备 DELE B2 考试的学生设计。

## 🚀 部署指南

### 1. 准备环境
确保你拥有 GitHub 账号和 [Google AI Studio](https://aistudio.google.com/) 的 API Key。

### 2. 部署到 Vercel (推荐)
1. 将此代码推送到你的 GitHub 仓库。
2. 在 Vercel 中导入该仓库。
3. **重要**：在 Vercel 的项目设置中，添加环境变量 `API_KEY`。
4. 点击部署，搞定！

## 🌟 主要功能
- **AI 动态出题**：每次练习都会生成全新的 10 道针对性题目。
- **弱点分析**：基于你的历史表现，AI 会自动分析你的语言盲点。
- **进度追踪**：记录学习时长、答题准确率和连续学习天数。
- **DELE B2 标准**：涵盖虚拟式、过去时态辨析、高级逻辑连词等核心考点。

## 🛠 技术栈
- React + TypeScript
- Tailwind CSS (UI)
- Google Gemini API (Intelligence)
- Recharts (Data Visualization)
